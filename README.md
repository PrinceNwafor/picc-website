# The Prevailers International Christian Chapel (PICC) — Website

Official website for **The Prevailers International Christian Chapel (PICC)**, a Spirit-filled
family church located on **Ilaje Road, Bariga, Lagos, Nigeria**. Led by **Pastor Elisha Esho**
alongside his wife, **Pastor Joyce Damilola-Dada**.

A mobile-first, fully responsive static site built with plain HTML, CSS and JavaScript.

## Highlights

- 🎬 **Video landing page** — a real PICC praise clip plays in the hero.
- 🎨 **Brand colours from the logo** — royal plum/magenta + warm gold.
- 📱 **Mobile-first & responsive** — no horizontal scrolling, faces framed properly in photos.
- 🖼️ **Gallery** — services & testimonies photos with a tap-to-zoom lightbox.
- 🪪 **Logo favicon** — appears on the browser tab.

## Pages

`index.html` (home) · `about.html` · `sermons.html` · `ministries.html` · `events.html` ·
`gallery.html` · `plan-visit.html` · `give.html` · `contact.html` · `beliefs.html` ·
`find-help.html` · `find-help-detail.html`

## Project structure

```
assets/img/      logo, favicons, photos (web-safe filenames)
assets/video/    landing.mp4 (hero), teaching.mp4 (sermon)

```
